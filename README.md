# 📊 Analytics Dashboard

موقع لوحة تحكم تفاعلية وإحصائيات متكاملة (Analytics Dashboard) تم بناؤها باستخدام أحدث تقنيات الـ Frontend. تتميز بتصميم متجاوب ورسوم بيانية تفاعلية لعرض البيانات بأسلوب عصري.

🌐 **[اضغط هنا لمشاهدة الموقع الحي (Live Demo)](https://nahlahamid415-tech.github.io/analytics-dashboard/)**

---

## ✨ المميزات (Features)

* 📱 **تصميم متجاوب (Responsive Design):** متوافق مع كافة الشاشات والأجهزة.
* 📈 **رسوم بيانية تفاعلية (Interactive Charts):** باستعمال مكتبة Chart.js لعرض أداء المبيعات.
* 🎨 **واجهة واضحة وأنيقة (Clean UI/UX):** بطاقات إحصائيات سريعة وجدول معاملات حديث.
* ⚡ **أداء سريع وهيكل منظم:** فصل تام بين أسطر HTML و CSS و JavaScript.
